RAJI AKKA'S BIRTHDAY SCRAPBOOK 💗

LIVE SITE
https://santhiswaroopa.github.io/raji-birthday/

RUN IT ON YOUR COMPUTER
1. Extract raji_birthday_website.zip.
2. Open the raji_birthday_website folder.
3. Double-click index.html. It opens in Chrome, Edge, Firefox, or another browser.
4. Keep the assets folder beside index.html; the photos must stay inside assets.

PHOTOS
- assets/sisters-photo-1.png is the uploaded sisters photo.
- assets/sisters-photo-2.png is a closer crop of that uploaded photo for the gallery.
- assets/pic1-portrait.jpeg is the upright version of the first gallery photo.
- To add a different memory, copy your photo into assets and update the matching img src in index.html. The layout automatically crops photos to fit the frames without stretching them.

BACKGROUND MUSIC
For copyright-safe music, use a song/audio file you have permission to use. Name it birthday-song.mp3 and put it inside the assets folder. The music button will then play/pause it. Browsers require a tap/click before audio can start.

PUBLISH IT FOR FREE WITH GITHUB PAGES
1. Sign in to GitHub and create a new public repository, for example raji-birthday.
2. Upload index.html and the assets folder (including the photos and your optional MP3) to the repository root.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch; select the main branch and / (root), then Save.
5. Wait for GitHub Pages to finish publishing. The Pages section will show the live URL; open it on your phone to test it.

You can also deploy the folder using Netlify Drop by visiting https://app.netlify.com/drop and dragging the extracted project folder into the page. Check the service's current account/sign-in requirements.

NOTES
- This is a static website; no server or database is needed.
- The birthday scrapbook is published with GitHub Pages at the live site link above.
- If you add a music file, make sure you have the right to use/share it.
